# Music Central

A Spotify-style music app for Windows and Android: search free music, build playlists, download songs for offline
listening, and connect your Spotify and YouTube accounts.

## Download the latest version: 2.0.1

| Device | Download |
|---|---|
| Windows | [MusicCentral-Setup-2.0.1.exe](v2.0.1/builds/MusicCentral-Setup-2.0.1.exe) |
| Android | [MusicCentral-2.0.1.apk](v2.0.1/builds/MusicCentral-2.0.1.apk) |

Install instructions and what's new: [v2.0.1/README.md](v2.0.1/README.md).
Already have Music Central? Use **Settings → Updates → Check for updates** in the app.

## How versions are kept
- **`main`** (this branch) only has the newest version.
- Every version also has its own branch with only that version in it:
  `release/v1.0.0`, `release/v1.1.0`, `release/v2.0.0`, `release/v2.0.1`, and so on.
  Pick one from the branch menu on GitHub to download an older version.
- [`latest.json`](latest.json) tells the app which version is newest and where its installers are.
