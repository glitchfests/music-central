# Music Central

A Spotify-style music app that searches free, legal music sources, builds playlists and downloads songs for offline listening.

Each version lives in its own folder. The newest is the one to use.

| Version | What's in it |
|---|---|
| [v1.1.0](v1.1.0/) | Installable apps: Windows installer and Android APK in [`v1.1.0/builds/`](v1.1.0/builds/). |
| [v1.0.0](v1.0.0/) | Search (Internet Archive, Audius, Jamendo), playlists, downloads for offline, importing your own files, player with queue, shuffle and repeat. Installable as an app. |
